# Data Analysis Dashboard

A modern, interactive data analysis application built with React and TypeScript. Upload CSV files, visualize your data with dynamic charts, and get AI-powered insights.

## 🚀 Features

- **Smart File Upload**: Drag-and-drop CSV files with real-time validation.
- **Interactive Charts**: Dynamic visualizations using Recharts (Bar, Line, Area, Pie, Scatter).
- **AI Insights**: Automated pattern recognition and data analysis.
- **AI Chat Interface**: Ask questions about your data in natural language.
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile.
- **Data Export**: Export processed data to CSV and insights to text reports.

## 🛠️ Technologies Used

- **Frontend**: React 18, TypeScript, Vite
- **UI Framework**: Tailwind CSS, shadcn/ui components
- **Data Visualization**: Recharts
- **Icons**: Lucide React

## 🏃‍♂️ Getting Started

### Prerequisites

- Node.js 16.0 or higher
- npm or yarn package manager

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd data-analysis-dashboard
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:5173](http://localhost:5173) in your browser.

## 📖 How to Use

1. **Upload Data**: Drag and drop a CSV file or click to browse.
2. **Explore Visualizations**: View your data in interactive charts in the "Charts" tab.
3. **Get Insights**: See automated analysis of patterns and trends in the "Insights" tab.
4. **Ask Questions**: Use the AI chat to explore your data further.
5. **Download Results**: Export insights and visualizations using the buttons in the header.
